# Career Quest interface inventory

The atlas release keeps the server as the authority for available identities, scoped data, and mutations. The client has eight screens. The table records their main action and the states shown to the user; a missing server permission remains a server error.

| Screen                 | Roles                        | Main action                                                                                                                              | Other states                                                                                                                   |
| ---------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| My path                | Employee                     | Review required assignment, request recommendations, preview an activity, add to plan, submit evidence                                   | No goal, no assignment, no candidate, AI fallback/unavailable, preview before credit, pending confirmation, route search limit |
| Practical projects     | All five, with scoped queues | Employee submits or revises; advisor approves/revises/rejects and accepts evidence; manager decides resources; supervisor decides policy | Queue by status, selected detail, pending criteria, evidence, decision history, empty queue                                    |
| People and assignments | Advisor, manager, HR         | Search/select employee; manager/HR assign; advisor confirms completion; manager resolves help                                            | Empty search, pending result/help, reason dialog, scoped profile loading/error                                                 |
| Analytics and import   | HR                           | Inspect aggregate and drill-down records; preview and apply import                                                                       | Empty denominators, direct coverage caveat, file replacement/removal, invalid preview, row errors, warnings                    |
| Catalog                | All roles                    | Search and inspect activity                                                                                                              | Audience, format, gains, prerequisites, dates, no results                                                                      |
| External opportunities | Employee                     | Search by skill and propose a found source as a practical project                                                                        | Unknown cost/duration/approval, unavailable search, empty results                                                              |
| Rewards                | Employee                     | View balance/history and request an available reward                                                                                     | Insufficient balance, empty history, ledger reasons                                                                            |
| Decisions and audit    | HR, supervisor               | Inspect dated decisions and structured details                                                                                           | Scoped empty log and technical details                                                                                         |

Desktop navigation uses the fixed sidebar. Tablet uses a menu. Phone navigation exposes three primary sections with compact visible labels and full accessible names, plus “More” for the remaining sections. The desktop header shows the current identity and role once; narrow phones reserve header space for the CQ mark and controls. Role switching, simulated date, and reset live in the demo dialog. All dropdowns share one accessible styled popup; long skill and activity lists search inside it. Every screen supports RU, KK, EN through client dictionaries and stable-ID source catalog translations. Unknown imported text and user comments retain their original language.

The first interface pass selected composition B in [DESIGN.md](../DESIGN.md). The code pass was verified with typecheck, build, the repository tests, and source integrity in the UI worktree. Browser and human-language reviews are recorded in the release acceptance report by the coordinator.
