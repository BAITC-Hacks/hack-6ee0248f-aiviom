# Сторонние компоненты, источники и вклад

Основание: [S-RULES §§5.4.4–6; S-FINAL §§2, 17–19, 21](SOURCES.md).

Это реестр для заполнения **по факту реализации**. Он не утверждает, что все упомянутые в плане библиотеки или модели уже используются. Не присваивать всему проекту MIT/Apache/другую лицензию без решения правообладателей и проверки ограничений источников.

## 1. Компоненты

| Компонент | Фактическая версия | Назначение | Источник/лицензия | Статус |
|---|---|---|---|---|
| Career Quest starter dataset | В meta доступной копии `1.0`; релизный archive hash требует фиксации | Original synthetic seed | Ограничения хакатона; не считать свободно распространяемым | Структура прочитана, deployment не проверен. |
| Runtime/package manager/framework | Не установлены | Исполнение приложения | Указать по code manifests | Не проверено. |
| React / SQLite из рекомендации стека | Не установлены | Возможные UI/DB компоненты | Уточнить только если реально выбраны | Предложение S-FINAL, не факт реализации. |
| ORM и библиотеки validation/testing | Не установлены | Хранение, contracts, tests | Перечислить зависимости и лицензии | Не проверено. |
| Продуктовый LLM provider/model | Не установлены | Реальный выбор/объяснение рекомендаций | Указать provider terms и actual model ID | Не проверено. |
| Search adapter, если реализован | Не установлен | P2 учебные источники | Источник, условия, реальные tools | Не проверено. |
| Codex | Фактически использованную конфигурацию заполнить | Помощь разработке | Инструмент разработки, не product inference | План/контекст использования не заменяет журнал работы. |
| Локальный impeccable | Версию/расположение/прочитанные инструкции подтвердить | Дизайн workflow | Локальный установленный источник | Не утверждать применение без проверки. |
| Templates/icons/fonts | Перечислить реально включённое | UI/assets | Право использования и лицензия | Не проверено. |

Для значимых reused компонентов раскрыть источник, объём адаптации и где находятся в коде. Не выдавать чужое готовое решение за разработку на хакатоне.

## 2. Оригиналы и extensions

Original JSON/CSV не переписываются. Demo extensions, учебные fixtures и policy examples имеют отдельное происхождение. Документационные файлы в `examples/` созданы как искусственные примеры структуры и не являются данными банка или скрытыми профилями жюри.

Не включать в публичное evidence jury uploads, личные credentials или ограниченный набор вне согласованного канала. Условия использования результатов по Положению не означают автоматически наличие отдельной open-source лицензии на все материалы.

## 3. Участники и фактический вклад

| Участник | Компонент/работа | Подтверждение: commit/PR/документ |
|---|---|---|
| Заполнить по фактическому составу команды | Не выдумывать вклад | Добавить реальные ссылки/IDs |

AI-агенты не являются вымышленными участниками команды. Их использование можно описать как инструмент с реальными изменениями/проверками. Количество агентов не является само по себе доказательством качества реализации.
