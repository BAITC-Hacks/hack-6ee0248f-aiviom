# Термины Career Quest

Словарь к [документации](00_NAVIGATION.md). Определения соответствуют использованию терминов в [S-FINAL](SOURCES.md).

| Термин | Понятное значение |
|---|---|
| Review baseline | Зафиксированные навыки на дату последней оценки. |
| Effective skills | Актуальное расчётное состояние: baseline плюс учитываемые подтверждённые результаты. |
| Projected skills | Навыки в симуляции будущего действия; реальные данные не изменяются. |
| Gap | Недостающие уровни относительно требования цели. |
| Critical skill | Навык, помеченный в целевом role profile как критический. |
| Coverage | Насколько закрыты требования цели по формуле §10.2; не вероятность повышения. |
| Progress | Какая часть исходного gap закрыта с начала конкретной версии плана. |
| Gain | Заданный прирост навыка за подтверждённый результат. |
| Cap / max_level | Максимум, до которого данная активность может поднять навык; не повод понизить более высокий уровень. |
| Prerequisites | Предварительные требования для допуска к действию. |
| Eligibility | Проверка, допустимо ли действие этому сотруднику сейчас. |
| Milestone | Условие подтверждённой компетенции/результата, а не обязательно определённый курс. |
| Roadmap | Маршрут действий и зависимостей к выбранной цели. |
| Side quest | Альтернативная развивающая работа, которая требует согласования критериев и проверки результата. |
| Approved | Предложение согласовано; навыки ещё не начислены. |
| Accepted | Результат проверен и принят; допустим однократный зачёт. |
| Evidence | Доказательство: исходный факт для рекомендации либо материал, подтверждающий результат работы. |
| Provenance | Происхождение значения: baseline, record/credit, правило и версия. |
| Ledger | Журнал начислений/списаний, позволяющий проверить происхождение итогового значения. |
| Skill credit | Уникальная запись подтверждённого зачёта навыка. |
| Reward credit/debit | Начисление/списание личных баллов по утверждённой политике. |
| Workspace | Изолированное пространство данных и действий, например отдельная demo-сессия. |
| Scope | Граница разрешённых данных и действий для конкретного пользователя/роли. |
| Idempotency | Повтор того же запроса не создаёт второе начисление или другую повторную мутацию. |
| Seed | Первоначальная загрузка данных для запуска. |
| Demo extensions | Дополнительные маркированные сценарии, не изменяющие исходный набор. |
| Live AI | Реальный вызов модели, а не заготовка или правило. |
| Cache hit | Использование ранее полученного ответа для тех же актуальных версий входов. |
| Rules fallback | Явно подписанный резервный ответ детерминированной логики. |
| Clean-room test | Проверка в чистой копии только по опубликованным инструкциям, без скрытого контекста разработчика. |
| Tested commit | Конкретная версия кода, на которой действительно выполнены проверки. |
