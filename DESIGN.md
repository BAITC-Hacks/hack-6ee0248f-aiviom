# Career Quest visual system

## Direction

An internal development workspace: calm light surfaces, graphite text and one restrained green for primary action and confirmed progress. The route and evidence carry meaning; no game imagery, leaderboard or decorative XP effects. Employee and reviewer screens share the same visual grammar.

## Layout and behavior

Desktop uses a 246px contextual sidebar and a two-column task area. Tablet collapses the sidebar to bottom navigation; narrow mobile stacks panels and keeps the role switcher accessible. Interactive controls have focus, hover, disabled and pending states. Information is never represented by color alone. Source activity and skill IDs stay canonical; `ru` labels are primary and `kk`/`en` interface dictionaries fall back to source names for data that has no approved translation.

The milestone spine represents verified requirements. The profile header separates coverage, critical requirements and plan progress. Mandatory HR assignments are in a separate lane from voluntary recommendations. Preview is an inline detail section and never implies a saved result. Side quest decisions carry explicit reasons and evidence.
